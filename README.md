# 🎮 Número secreto

---

## 📌 Sobre o projeto
O **Jogo Do número secreto** é uma aplicação web interativa desenvolvida com foco em lógica e experiência do usuário. O projeto explora conceitos fundamentais de desenvolvimento front-end, proporcionando uma experiência simples e dinâmica diretamente no navegador.

---

## 🚀 Tecnologias utilizadas
- HTML5  
- CSS3  
- JavaScript  

---

## 🎯 Funcionalidades
- Interface interativa  
- Lógica de jogo implementada em JavaScript  
- Feedback visual ao usuário  
- Execução direta no navegador  

---

## 💡 Objetivo do projeto
Este projeto foi desenvolvido com o objetivo de:
- Praticar lógica de programação  
- Trabalhar manipulação do DOM  
- Desenvolver habilidades em JavaScript  
- Criar uma aplicação funcional e acessível via web
